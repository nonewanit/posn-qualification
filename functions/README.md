# ฟังก์ชัน (Functions)

## หัวข้อย่อย

เรียงตามลำดับที่แนะนำในการศึกษา:

| ลำดับ | หัวข้อ | โฟลเดอร์ | เนื้อหา |
|---|---|---|---|
| 1 | ความสัมพันธ์และฟังก์ชัน | [relations/](relations/) | นิยาม, โดเมนและเรนจ์, ประเภทของฟังก์ชัน, ฟังก์ชันประกอบและผกผัน, สมบัติของความสัมพันธ์ |
| 2 | พหุนาม | [polynomials/](polynomials/) | การบวก ลบ คูณ หารพหุนาม, การแยกตัวประกอบ |
| 3 | ฟังก์ชันกำลังสอง | [quadratic/](quadratic/) | รูปแบบทั่วไป, กราฟพาราโบลา, จุดยอด, แกนสมมาตร |
| 4 | ฟังก์ชันเอกซ์โพเนนเชียลและลอการิทึม | [exp-log/](exp-log/) | กราฟ, สมบัติ, การแก้สมการ |
