# เรขาคณิต (Geometry)

## หัวข้อย่อย

เรียงตามลำดับที่แนะนำในการศึกษา:

| ลำดับ | หัวข้อ | โฟลเดอร์ | เนื้อหา |
|---|---|---|---|
| 1 | เรขาคณิตวิเคราะห์และเวกเตอร์ | [analytic/](analytic/) | ระนาบพิกัด, ระยะทาง, จุดกึ่งกลาง, ความชัน, สมการเส้นตรง, มุม, เวกเตอร์ |
| 2 | มุม | [angles/](angles/) | ชนิดของมุม, มุมตรงข้าม, มุมภายใน, เส้นขนาน |
| 3 | สามเหลี่ยม | [triangles/](triangles/) | ความเท่ากันทุกประการ, ความคล้าย, ทฤษฎีบทพีทาโกรัส |
| 4 | วงกลม | [circles/](circles/) | คอร์ด, เส้นสัมผัส, ทฤษฎีบทเกี่ยวกับวงกลม |
| 5 | รูปสองมิติ | [2d/](2d/) | รูปหลายเหลี่ยม, รูปนูน/เว้า, พื้นที่, เส้นรอบรูป |
| 6 | รูปสามมิติ | [3d/](3d/) | ปริซึม, ทรงกระบอก, กรวย, ทรงกลม, พีระมิด, ปริมาตร, พื้นที่ผิว |
