## โครงสร้างของแต่ละหัวข้อ

แต่ละหัวข้อประกอบด้วยสไลด์และแบบฝึกหัด (รวม 3 ไฟล์ PDF):

```
<topic>/
├── slides/main.pdf        # สไลด์สำหรับใช้สอน
└── exercises/
    ├── exercise.pdf       # ใบงานสำหรับนักเรียน
    └── answer-key.pdf     # เฉลยสำหรับผู้สอน
```

## แบบฝึกหัด

แต่ละหัวข้อมีแบบฝึกหัดในโฟลเดอร์ `exercises/` ประกอบด้วยไฟล์ PDF 2 ไฟล์:

| ไฟล์ PDF | คำอธิบาย |
|---|---|
| `exercise.pdf` | **ใบงาน** — โจทย์พร้อมที่ว่างสำหรับเขียนคำตอบ เรียงจากง่ายไปยาก |
| `answer-key.pdf` | **เฉลย** — คำตอบของทุกข้อ (ไม่มีวิธีทำ) |

## สไลด์

สไลด์ทั้งหมดอยู่ในโฟลเดอร์ `slides/` ของแต่ละหัวข้อ ใช้กล่องสี 4 แบบที่ใช้ทั้งโปรเจกต์:

| กล่อง | สี | ใช้สำหรับ |
|---|---|---|
| `explanation` | 🔵 ฟ้า (Blue) | นิยาม, แนวคิด, หมายเหตุ |
| `exambox` | 🟢 เขียว (Green) | ตัวอย่าง, โจทย์ |
| `solbox` | 🟠 ส้ม (Orange) | วิธีทำ, เฉลย |
| `intuition` | 🟣 ม่วง (Purple) | คำอธิบายแบบเข้าใจง่าย |
